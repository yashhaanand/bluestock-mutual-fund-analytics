# Mutual Fund Analytics

## Bluestock Fintech Internship – Capstone Project

### Project Overview

This project implements an ETL pipeline for Mutual Fund Analytics. It includes data ingestion, validation, exploration, and live NAV integration using the MFAPI service.

- Pandas
- NumPy
- Requests

- Jupyter Notebook
- Git & GitHub
